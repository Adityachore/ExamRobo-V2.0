# Brain File Manifest

This folder contains only Markdown planning/specification files. Files 00–18 define the product and architecture baseline. Files 19–35 provide the actionable implementation, verification and project-control layer. File 36 is the authoritative business/product decision register. File 37 is the page inventory and UI design map. `README.md` is the navigation index.

**No source code, SQL migrations, tests, environment secrets or production configuration are included.** Executable artifacts belong in the application repository.
